# SORAZUM MVP

SORAZUM — платформа коллективного разума для решения реальных оплачиваемых задач.

Компании и государство размещают миссии, люди сами присоединяются, а ИИ собирает несколько сильных команд, сравнивает их материалы и помогает объединить лучшие совместимые части в один результат.

## Что работает

- каталог оплачиваемых миссий и фильтры;
- карточка задачи и вступление без отбора;
- демонстрация ИИ-сборки сбалансированной команды;
- рабочее пространство команды с задачами и чатом;
- интерактивный ИИ-синтез материалов;
- кабинет заказчика и публикация новой миссии;
- адаптивный интерфейс для компьютера и телефона.

## Запуск в Cursor

1. Откройте папку `sorazum-mvp`.
2. Выполните `npm install`.
3. Выполните `npm run dev`.
4. Откройте `http://localhost:3000`.
